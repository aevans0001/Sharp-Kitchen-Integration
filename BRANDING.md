# Branding Preparation

Home Assistant 2026.3 and later allows custom integrations to ship branding
inside `custom_components/sharp_kitchen/brand/`.

Planned assets:

- `brand/icon.png` — square integration icon.
- `brand/[email protected]` — optional high-resolution square icon.
- `brand/logo.png` — optional horizontal logo.
- Dark-mode variants only if the normal artwork does not remain legible.

## Release constraints

Do not copy Sharp corporate artwork, product photography, or trademarks into
this repository unless reuse rights are clear. A neutral original microwave-
drawer/integration mark is the preferred fallback for this unofficial project.

The final PNG assets should be added only after the visual direction is
approved. Branding is preparation work only and does not authorize a release.
